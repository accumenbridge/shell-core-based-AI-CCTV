## Additional P2 source-search finding

`modules/veyviz-sources/src/index.ts:35,122` folds the query with JavaScript Unicode `toLowerCase()` but folds persisted names with SQLite built-in `lower()`. Valid registered names are not ASCII-restricted. A name such as Étage searched verbatim becomes étage on the input side while SQLite keeps Étage on the row side, so exact-name search fails on both source-owned and delegated routes. The source owner uses plain node:sqlite DatabaseSync and installs no lower override. Use consistent ASCII-only query folding with non-ASCII literals retained, or an explicitly reviewed owner-local consistent function; keep query/SQL/cursor normalization identical, and add a valid non-ASCII exact-name regression.
