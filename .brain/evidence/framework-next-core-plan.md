Operation metadata is a requirement and discoverability surface, never a grant. Product exposure policy belongs outside maintained hosts. Shared Node/browser module execution is trusted reviewed code, not an untrusted sandbox. Builds select fixed implementations; installation or upgrade produces a new reviewed immutable snapshot. Revocation disables access and retains owner data by explicit policy; destructive purge is separate.

The next SDK/tooling increment must document compatibility envelopes, exact module/package versions, reviewed install/upgrade/remove behavior, migration ownership, exported closure and a tested developer example. Avoid a speculative capability catalogue. Select one production identity/persistence/runtime profile only after its environment choices and authority are concrete; native mobile HTTPS/OIDC remains deferred.
