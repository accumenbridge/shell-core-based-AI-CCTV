# Owned intelligence extension contract

The first recorded v1 requests/results remain readable. New requests optionally capture `processing`: categories (`person`, `vehicle`, `animal`), explicitly selected CPU or CUDA execution, motion threshold/heartbeat, visual/face/plate feature switches and the SHA-256 of an operator-installed runtime profile. The runtime profile binds executable, package inventory, fixed worker code and model/tokenizer bytes. Browsers cannot select paths, URLs or interpreters.

New results add optional labelled category-qualified appearances, normalized visual/face vectors with model identities, uncertain OCR plate candidates, and processing evidence. Samples skipped by motion are recorded separately from measured inference samples. A skipped frame cannot establish absence. Matching never crosses categories. Face and image retrieval return possible visual matches, never personal identities. Automatic appearance grouping is an estimate; reviewed anonymous entity links are a separate Product fact.

Product additions remain in the intelligence owner: durable batches/watch intents, accepted-event alerts and acknowledgements, reviewed appearance/entity links, scoped vector retrieval and summaries derived only from accepted results. All operations preserve original actor/tenant/Product scope and recheck authority. Batch runs retain individual evidence identities; cross-recording totals do not silently collapse repeated appearances. Every new route uses existing independently granted intelligence read/write permissions.

Long recording and live input are operator tools. They produce bounded immutable MP4 segments, admit exact bytes with optional observed first-frame UTC plus uncertainty, and feed the same Product acceptance path. Live cameras use a private operator profile, never a browser-supplied network URL. Live alert latency includes segment closure and analysis time; a replay test does not qualify a physical feed. Capture stops when its bounded duration/catalog budget is exhausted. It never deletes recordings.

Root owns the finite implementation paths: intelligence src/protocol, validation, index, UI/styles, feature bridge and analytics helpers; owned Python temporal/runtime setup/worker/bridge/tests; owned recording ingest tools and related focused tests/docs. Maintained packages/apps, original legacy sources and the existing pinned CPU companion remain unchanged. Independent review is read-only.
