# Paired runtime wiring — source-grounded checklist

Sol/high read-only plan, 2026-10-01. Existing CP4 contract governs; this checklist does not qualify implementation, native execution, HTTP or browser behavior.

`apps/control-plane/src/main.ts`: create the runtime manager after the artifact store, independently of the optional build-worker setup. Pass it to the operator. Capability/prose must distinguish runtime attachment from compiler availability, legacy deployment REQUESTED and unattached model-serving execution. Signal runtime closing synchronously before awaiting HTTP drain. Keep store/registry available while owned callbacks can still reconcile; aggregate original/resource errors without closing dependencies underneath live helper/monitor callbacks. Retain uncertain material.

`apps/control-plane/src/operator-server.ts`: fixed authenticated collection/detail/structured-log reads under `/platform-api/runtime-instances`; confirmed collection start `{confirm:true,productId,version,requestKey}`, and instance stop/restart `{confirm:true,requestKey}`. Preserve exact-envelope, Host/Origin, content type, body bounds and session rules. Recheck the same captured session after protected body reads and awaited success or rejection, passing that closure through manager/store after BEGIN. Never recapture a newly paired actor. Map runtime errors to bounded fixed public codes/messages; no owner token, nonce, configuration, seed, credentials, private paths, raw logs or filesystem errors in DTOs.

`apps/control-plane/src/source-import.ts`: expose runtime capability independently of worker/compiler attachment. Keep declarations and actual executors distinct.

`apps/studio-web/src/main.ts`: launch from source-derived promoted releases; capture immutable product/version/artifact selection and command key. Separate instance stop/restart confirmation, disable duplicate pending submissions and preserve the key for equal retry. Render state, selected worker requirement, API/worker facts, process observation and uncertain reservation distinctly. Escape public detail/events. Apply session and selection/load generations to all success/error assignments; clear polling and selections at disconnect/401/pair/navigation. Draft edits do not alter the launch target. Refresh must not silently reuse obsolete confirmation.

Meaningful qualification: actual HTTP negatives assert no command/slot/files; actual promoted Service Desk write/positive stop/restart; registered runtime succeeds without compiler; actual logout-after-verification/enrollment and independent Node SQLite expiry. Ordinary browser pairs, selects exact release, proves unchecked Start does not admit, confirms start, inspects public facts/log, stops/restarts and disconnects/re-pairs. Private runtime credentials remain fixture-only. Controlled-delay browser blocks stay blocked; no eval/interception/CSP workaround. Native, direct manager, HTTP, browser, full npm test/verifier and independent final candidate review are separate gates.
