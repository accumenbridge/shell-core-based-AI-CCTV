# Executable module operations

Modules may contribute optional, versioned operation descriptors. A descriptor is bounded discoverability data; it does not grant access. The selected module must register exactly one trusted handler with the same descriptor, and the host checks module permissions, current mode, tenant scope and the original authenticated session before and after an awaited handler.

The current neutral JSON-schema subset supports objects with declared properties and no additional properties, required fields, strings with length and constrained pattern checks, safe integers with bounds, booleans, bounded arrays, and enumerations. It rejects unknown keywords, cycles, non-JSON values and oversized inputs/outputs. The fixed limits are 16 KiB per schema, 512 KiB per input, 128 KiB per output, traversal depth 8, 32 properties per object, 1,024 array items and 4,096 visited values. This is a deliberately small subset, not a claim of full JSON Schema compatibility.

Knowledge provides `knowledge.documents.search@1` and `knowledge.documents.get@1` under `knowledge.read`, plus `knowledge.documents.create@1` under `knowledge.write`. Search returns only bounded snippets from indexed, ready documents in the current tenant. Get returns a bounded excerpt and body digest. Create uses the existing Knowledge command receipt and transaction with a caller-supplied stable command ID, so an HTTP retry and an operation retry share the same idempotency identity. Search/get expose no job records or storage details.

`ApplicationHost.operationCatalogue` and `invokeOperation` are in-process trusted adapter seams. No HTTP route, MCP server, user-selected handler, actor/tenant fields in operation input, remote authentication model, or plugin sandbox is added. A future adapter must supply identity and scope from its own reviewed authenticated boundary. If the original session expires or cancellation arrives while a handler is awaiting, the host suppresses the late response; a committed owner write is not described as rolled back.

Knowledge and Combined select Knowledge/Handoff 0.2.2. Earlier exported snapshots remain tied to their captured manifests and package closures; rebuilding current sources does not rewrite them. The offline Studio preview uses the same compiled pure operation validator through its fixed four-module browser closure and remains data-only.
